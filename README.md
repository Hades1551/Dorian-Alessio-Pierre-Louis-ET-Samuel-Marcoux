# Dorian-Alessio-Pierre-Louis-ET-Samuel-Marcoux
Projet 1 Microcontrolleur 2

README
 
Test de la matrice

Conçu par Samuel Marcoux et Dorian Alessio Pierre Louis
 
Description
 
Ce projet permet de tester l'ensemble des fonctionnalités de l'interface matrice, soit :
 
- La matrice DEL

- Les 3 DEL

- Les 8 boutons

- Le potentiomètre

- L'encodeur

- La photocellule
 
 
Fonctionnement du programme
 
Le programme permet de vérifier le fonctionnement de chaque composant :
 
- Matrice DEL : Affiche un test visuel permettant de vérifier le fonctionnement de chaque DEL individuelle.

- Les 3 DEL : Les boutons A, B et C permettent respectivement d'allumer les trois DEL en vert, rouge et bleu.

- Les 8 boutons : Lorsqu'un bouton est appuyé, la matrice affiche lequel a été activé.

- Potentiomètre : Affiche sur la matrice la valeur actuelle du potentiomètre.

- Encodeur : Affiche la valeur actuelle de l'encodeur sur la matrice.

- Photocellule : Affiche la valeur actuelle mesurée par la photocellule sur la matrice.
 
 
 
Librairies nécessaires
 
Deux librairies sont nécessaires au fonctionnement du projet :
 
- <MOMO_RGB_Matrix.h> : Permet de contrôler et de faire fonctionner la matrice DEL.

- <bits_manip.h> : Simplifie la manipulation et la configuration des bits.
